# 首批功能迁移：额度中枢与绘图同步

本阶段将两项功能的入口和管理界面迁移到 React；账号加密、模型调用、绘图存储和 iPad 同步仍由原工具箱进程执行。这是兼容阶段，完整迁移其他工具尚未完成。

## 保留的数据

- 原 `config.json` 中的字体和 API 配置：只读取字体偏好，不覆盖原文件。
- `ai-hub/state.json`：沿用加密账号、网关密钥、模型和调度顺序。只有用户保存模型／优先级、刷新额度或发送请求时才调用旧服务的对应操作。
- `localsend.json` 与 `drawing-sync/pairing.json`：保持设备 ID、编号和配对令牌。
- `drawing-sync/notebook.json` 与 `assets/`：复用原绘图本，无需导入、清空或换新本。
- V2 自己的文献与笔记仍保存在独立目录，不与旧版混写。

所有路径均从当前用户的系统目录解析，不依赖某台机器的盘符。Windows 目录联接自然沿用其实际数据位置。

## 安装兼容控制器（开发维护）

需要 Windows 已安装正式旧版 **0.46.26**。补丁只验证过该版；其他版本会停止准备。它不自动下载或修改第三方客户端。

1. 在 V2 仓库执行 `npm ci`，再执行 `npm run legacy:prepare`。脚本从原安装提取档案，在 `work/` 生成补丁，检查语法并保留原生文件的展开标记；尚不修改原安装。
2. 正常停止原工具箱中的 DSH 等子服务，再退出旧工具箱。安装脚本发现原程序仍运行就会停止，不会强杀进程。
3. 用 PowerShell 7 执行 `./scripts/install-legacy-bridge.ps1`。脚本核对准备前后的文件哈希、备份原 `app.asar`，替换档案并确认 `config.json` 没有变化；失败时恢复原档案。原 `.unpacked` 文件与用户数据均不替换。
4. 重新打开旧工具箱，再打开 V2。左侧点击对应模块即可；未运行时可点「连接现有工具箱」启动原安装。

需要重新准备已核对过的暂存目录时，可执行 `npm run legacy:prepare -- --reuse-stage`。安装后应将同一源码补丁同步到旧仓库，或在日后升级旧版后重新适配，避免旧版更新覆盖兼容控制器。仓库提供 `compat/patch-legacy.cjs`，只按已验证的锚点修改服务注册，不替换其他功能。

## 日常使用

额度中枢进入后显示原有账号快照及更新时间，点「刷新额度」才进行上游查询。更换模型时选择原服务返回的目录，再保存；上游不提供目录的兼容通道允许填写模型。账号过期、重新登录和新增通道暂在原额度中枢中处理。旧服务状态中的“可调度”表示配置齐备，不承诺上游账户当前一定接受请求。

绘图同步启用后加载原本，iPad 用原应用连接。二维码默认收起；网络地址变化时可展开选择正确网卡。V2 关闭后原服务仍可供 iPad 使用；要关闭局域网监听，点击「停止同步」或退出旧工具箱。

## 恢复

如果兼容控制器异常，退出两版应用和旧版子服务，把 `work/legacy-backup-时间/app.asar` 复制回旧安装的 `resources/app.asar` 即可恢复旧程序。不要删除或覆盖用户数据目录。无需更换账号、字体、设备 ID 或配对文件。

## 验证范围

自动检查分三层：独立 Node 服务与桥接测试；隔离数据的真实 Electron 页面测试；本机原账号和绘图本的接入验证。隔离测试验证通道模型编辑、启停、额度格式、字体读取、二维码默认收起和原配置不被改写。旧服务已有的绘图测试覆盖两个客户端、图片、事件流、断线快照和 PencilKit 数据持久化。

本机迁移检查已比对字体、API 设置、通道凭据与原路由、网关密钥、设备身份、配对文件和绘图本。仓库不收录这些真实文件、配对二维码、私有截图或原软件二进制。iPad 当前是否在线，以页面远端连接状态为准。
